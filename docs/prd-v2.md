# StyleGrabber v2.0 — PRD (Analysis & Insight Suite)

## 1. 개요

StyleGrabber v2.0은 경쟁사 디자인 시스템의 **'시각적 실체'**와 **'수치적 데이터'**를 나란히 배치하여, 디자이너가 디자인의 의도를 직관적으로 파악하고 의사결정할 수 있도록 돕는 분석 솔루션임.

## 2. 핵심 고도화 기능 (Key Features)

### 2.1. 세션 기반 사이드-바이-사이드(Side-by-Side) 뷰

- **통합 세션 프레임:** 피그마 캔버스 생성 시, [원본 캡처(Visual)]와 [분석 리포트(Data)]를 하나의 Auto Layout 컨테이너로 묶어 생성.
- **시각적 매칭:** 리포트의 특정 스타일 카드를 클릭하면, 원본 캡처본에서 해당 요소가 위치한 영역을 하이라이팅하는 인터랙션 지원.

### 2.2. 컨텍스트 기반 진단 리포트 (Audit Report)

- **시스템 스코어링:** 디자인 일관성(Consistency)과 파편화(Fragmentation) 정도를 종합하여 0~100점 점수 부여.
- **이슈 탐지 엔진:**
  - 폰트 믹스(Font Mix): 동일 요소 내 다수 폰트 사용 탐지.
  - 파편화 경고(Fragmentation Warning): 특정 태그(span, a 등)에 과도한 스타일 변종 탐지.
- **Selector Consistency:** 각 컴포넌트별 사용 빈도 및 표준 준수율(% 단위) 시각화.

### 2.3. 스마트 데이터 정제 (Cleaned Rendering)

- **대표값(Base Token) 추출:** 불필요한 미세 오차값을 제거하고 서비스 핵심 스타일인 'Cleaned Token'으로 재구성.
- **데이터 요약:** 리포트 결과를 바탕으로, 해당 사이트에서 가장 핵심적인 컬러 팔레트와 타이포그래피 규칙만 뽑아 'System View' 생성.

## 3. 구현 로드맵

| 단계 | 기능 | 상세 목표 |
| :--- | :--- | :--- |
| **Phase 1** | 통합 세션 구축 | 캡처본과 분석 리포트 연동 아키텍처 구현 |
| **Phase 2** | 디자인 감사 리포트 | System Score 및 이슈 탐지 알고리즘 적용 |
| **Phase 3** | 정제된 시스템 렌더링 | 파편화된 데이터를 통합한 Cleaned 디자인 시스템 생성 |

## 4. 디자이너를 위한 가치

- **직관적 이해:** 데이터만 볼 때보다 원본 캡처를 함께 볼 때 디자인 의도 파악 시간 대폭 단축.
- **논리적 근거:** 시스템 점수와 이슈 리포트를 활용하여 우리 서비스의 디자인 시스템 표준 수립 및 설득 비용 절감.
- **전문성 강화:** 단순 추출을 넘어 '디자인 진단'이 가능한 전문가용 분석 도구로 차별화.

## 5. 기대 효과

- 경쟁사의 디자인 파편화 실태를 객관적 지표로 파악하여 자사 시스템 구축 시 반면교사로 활용.
- 디자이너와 개발자 간의 디자인 토큰 협의를 위한 명확한 소통 도구로 활용.
